
# Font Mountain

Font display and preview page which is made by pure JS.

## Techs

* HTML
* CSS
* JS

## Highlights

* Global state management with pub/sub + singleton
* Instant preview change by typing. 
* All changes affect everywhere.
* Letter change by scrolling.
* Selected font history.
